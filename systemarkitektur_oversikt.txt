SCENARIO 2: BRUKER KLIKKER PÅ EN ORDRE (går til /order/:orderId)
═══════════════════════════════════════════════════════════════════════════════════════

  Bruker klikker på <Link to={`/order/${order.orderid}`}>
       │
       ▼
  React Router matcher "/order/:orderId"
  → useState(null) for order lages på nytt (komponent mountes)
       │
       ▼
  Order.jsx useEffect(, [orderId]): KJØRER
       │
       │  GROQ med parameter $orderId:
       │  *[_type == "order" && orderid == $orderId][0]{
       │    _id, orderid, status,
       │    products[]{ quantity,
       │      product->{ productname, price, "imageUrl": image.asset->url }
       │    }
       │  }
       │
       ▼
  sanityClient.fetch(query, { orderId })
       │
       ▼  ← Ordre-objekt returneres
       │
  setOrder(data) → React re-renderer
       │
       ▼
  ┌──────────────────────────────────────┐
  │ Order Details                        │
  │ Order ID: abc123                     │
  │ Status: [open ▼]                     │
  │  ┌────┬─────────┬───┬──────┬──────┐  │
  │  │Bilde│Product  │Qty│Price │Total │  │
  │  ├────┼─────────┼───┼──────┼──────┤  │
  │  │ 🖼 │Laptop X │ 2 │$999  │$1998 │  │
  │  │ 🖼 │Mouse Y  │ 1 │ $49  │ $49  │  │
  │  └────┴─────────┴───┴──────┴──────┘  │
  └──────────────────────────────────────┘
       │
  BRUKER ENDRER STATUS TIL "packed":
       │
       ▼
  handleStatusChange kalles:
       │  1. setSaving(true) → "Saving..." vises
       │  2. sanityClient.patch(order._id)
       │       .set({ status: newStatus })
       │       .commit()
       │     → PATCH-forespørsel til Sanity
       │  3. setOrder({ ...order, status: newStatus })
       │  4. setSaving(false)
       │
       ▼
  ┌──────────────────────────────────────┐
  │  Sanity-databasen oppdateres:        │
  │  order.abc123.status → "packed"      │
  └──────────────────────────────────────┘

SCENARIO 5: BRUKER SØKER ETTER KUNDE
═══════════════════════════════════════════════════════════════════════════════════════

  Search.jsx: Bruker skriver "John" i input-feltet
       │
       ▼
  useState oppdaterer query for hvert tastetrykk
  (controlled component: value={query} onChange={setQuery})
       │
  Bruker trykker "Search" → handleSubmit kalles
       │
       ▼
  navigate(`/search?q=${encodeURIComponent(query)}`)
       │
       ▼
  React Router matcher "/search"
       │
       ▼
  SearchResults.jsx:
  useSearchParams() leser ?q=John
       │
       ▼
  useEffect(, [q]): KJØRER
       │
       │  GROQ: *[_type == "customer" && (firstname match $term ||
       │         lastname match $term || email match $term)]
       │        { _id, firstname, lastname, email, city }
       │        | order(lastname, firstname)
       │  $term = "*John*"  (wildcard = contains-søk)
       │
       ▼
  sanityClient.fetch(query, { term: `*${q}*` })
       │
       ▼
  setResults(data), setLoading(false) → React re-renderer
       │
       ▼
  Viser søkeresultater eller "No customers found matching ..."

  │     Bruker → React-komponent → useEffect → sanityClient.fetch(GROQ)      │

  │                                                                           │
  │  🔄 STATE:                                                               │
  │     Kun lokal useState i hver komponent. Ingen global state (Context).    │
  │     loggedInUser prop-dilles App → Layout → Frontpage.                   │

  │     React Router v7, nested routes med Layout + Outlet.                  │

  │                                                                           │
  │  🗄 SCHEMAS:                                                              │
  │     6 typer: admin, category, customer, product, order, orderproduct.    │
  │     5 dokumenter + 1 embedded objekt (orderproduct).                     │
  │     Relasjoner via references: order → customer, orderproduct → product, │
  │     product → category.                                                  │
  │                                                                           │
  │  🔍 GROQ:                                                                │
  │     6 spørringer totalt. Viktige features:                               │
  │     • Reference dereference: product->{ price }                          │
  │     • Wildcard match: firstname match $term                              │
  │     • Joined queries: { "key": *[...], "key2": *[...] }                  │
  │     • Bilde-URL: "url": image.asset->url                                 │
  │                                                                           │
  │  🎨 CSS:                                                                 │
  │     Ren CSS (3 filer). Ingen Sass. CSS-variabler, flexbox, grid,         │
  │     sticky navbar, media queries for responsivitet.                      │
  │     For Sass: npm install -D sass, bytt .css til .scss.                 │
  │                                                                           │
  └────────────────────────────────────────────────────────────────────────────┘
